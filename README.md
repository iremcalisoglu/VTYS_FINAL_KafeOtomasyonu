# KafeOtomasyonu
# ☕ Kafe Otomasyonu

Bu proje, bir kafe otomasyon sistemi geliştirmek amacıyla C# WinForms ve MySQL kullanılarak hazırlanmıştır.

Projede müşteriler, ürünler, siparişler, stok işlemleri ve ödemeler yönetilebilmektedir. Ayrıca veritabanı tarafında procedure, trigger ve function yapıları kullanılmıştır.

---

# 🚀 Kullanılan Teknolojiler

- C#
- WinForms
- MySQL
- Katmanlı Mimari (BL - DAL - UI)

---

# 📂 Proje Modülleri

## 👤 Müşteriler
- Müşteri ekleme
- Güncelleme
- Silme
- Arama işlemleri

## 🍔 Ürünler
- Ürün ekleme
- Güncelleme
- Silme
- Fiyat işlemleri

## 🛒 Siparişler
- Sipariş oluşturma
- Sipariş listeleme

## 📦 Stok
- Stok görüntüleme
- Stok güncelleme
- Trigger ile otomatik stok azaltma

## 💳 Ödemeler
- Ödeme ekleme
- Müşteri bakiyesi hesaplama

## 📊 Raporlar
- Toplam sipariş
- Toplam ödeme
- Toplam müşteri sayısı
- Toplam ürün sayısı
- KDV’li toplam tutar

---

# 🛠 Veritabanı Özellikleri

Projede MySQL üzerinde:

- Stored Procedure
- Trigger
- Function
- Foreign Key

yapıları kullanılmıştır.

---

# ⚡ Function Kullanımı

Projede örnek olarak:

- KDV_Hesapla
- Stok_Durum

functionları kullanılmıştır.
